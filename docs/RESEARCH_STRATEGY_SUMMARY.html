TRIFECTA research strategy — summary for team discussion

Short overview for colleagues working on the English annotation track. Dutch pipeline details live in ANNOTATION_STRATEGY.md; label alignment in LABEL_MAPPING_EN_NL.md.

What we are building

TRIFECTA annotates historic food-related text in three steps:

Step Question
A Is the target word a food entity in context (or metaphor / out of scope)?
B Which macro-frame applies: COOKING_CREATION, CURE, INGESTION, PRESERVING, or NONE?
C Which qualia roles fill the frame (technique, patient, affliction, etc.)?

The Dutch track works on KWIC snippets (concordance windows around a target word) from VOC/recipe corpora, with LLM-assisted batch annotation and a hand-curated gold set for evaluation.

The English track (INCEpTION / WebAnno) annotates full documents with token spans. We share the same frame vocabulary and Step A/B/C semantics, but not the same snippets or record_ids.

What the first evaluation cycle taught us

After ~100 hand-labelled Dutch gold rows and LLM comparison:

Finding Implication
Step B frame accuracy ~76% (best model: qwen2.5-coder / 14B instruct) LLM is usable as silver labeler, not yet gold-quality
~49 disagreement rows vs model Useful for error analysis, not as the only sampling plan
PRESERVING almost absent in gold (1 row) Per-frame F1 for rare frames is meaningless until we sample for them
Effort clustered on polysemous lemmas (water, brood, boter) Lemma-driven gold expansion loops without improving practice coverage

Main insight: the bottleneck is not “more labels on disputed words” but what kind of text we annotate and whether the passage is in scope at all.

Agreed direction: layered annotation

Instead of one flat TRIFECTA pass on every snippet, we use a stack:

Layer 0 — text_regime     What kind of text is this?
                          RECIPE_PRACTICE | MEDICAL | TRAVEL | LITERARY | ADMIN_TRADE | SCIENTIFIC

Layer 1 — Step A          Is this snippet in scope for food-practice annotation in this regime?

Layer 2 — Step B          Macro-frame, interpreted in light of regime
                          (e.g. PRESERVING mainly in recipes; NONE common in travel/literary)

Layer 3 — Step C          Qualia / semantic roles (technique, medium, affliction, …)

Why: A recipe and a travelogue use the same target word differently. Mixing genres in one gold pool produces arguments that look like frame errors but are really genre mismatch. Evaluation should be stratified by regime, not one headline F1.

Future simplification (under discussion): a coarse frame phase first (FOOD_TRANSFORM / MEDICAL_CURE / CONSUMPTION / OUT_OF_SCOPE), then split COOKING vs PRESERVING only when justified.

Gold labelling strategy (Dutch track)

Purpose

Gold is a small, deliberate reference set for:

  • Measuring LLM and (later) GijsBERT performance
  • Documenting hard cases in an edge bank
  • Driving sampling policy — not unlimited growth from the disagreement queue

How rows enter gold

  1. Export candidates — stratified by source (food terms, frame verbs) and phenomenon (e.g. preservation scenes), not only by model disagreement.
  2. Hand-label in CSV or trifecta-gold-ui (Step A + B + optional notes; text_regime dropdown).
  3. Merge batches into a master CSV; import only rows with labelled=true.
  4. Run LLM batch on the same eval inputs; compare with trifecta-eval.

Rules we are adopting

Rule Rationale
Cap per lemma (e.g. max 2 rows per target word) Stops water-style spirals
Sample by phenomenon and regime Grow PRESERVING, medical cure, etc. on purpose
Core gold vs edge bank Headline metrics on clear cases; ambiguous rows held separately
Disagreement CSV for adjudication keep_gold / adopt_pred / manual override — not automatic relabelling

Current scale: ~123 labelled Dutch rows; eval batch still aligned to 100 inputs until rebuilt.

English track: how it fits

Do not merge English and Dutch gold by snippet — there is no shared record_id. Run a parallel English eval track with the same schema and reporting.

Topic English track Dutch track
Tool INCEpTION / WebAnno CSV + gold UI
Unit Full document, token spans KWIC snippet + target_word
Guidelines Annotation_Guidelines_final.pdf (primary) Dutch PDF + same frames
Labels WebAnno *_LU spans JSON / CSV fields (mapping doc)
Regime Tag EN documents separately (same regime enum) text_regime on gold CSV
Eval en_gold + metrics per regime gold.parquet + trifecta-eval

Where English colleagues add most value

  1. Schema calibration — WebAnno exports as reference gold/silver for frame and qualia boundaries.
  2. Regime-aware sampling — English recipe books, medical texts, travel writing as separate pools.
  3. Closed phenomena — e.g. preservation techniques (parallel to Dutch preservare work: salting, smoking, drying).
  4. Guidelines stress-testing — cases where COOKING vs PRESERVING vs CURE is genuinely unclear across genres.

What we tried for cross-lingual help

English glossary hints in Dutch LLM prompts (Dutch target → English gloss) showed little gain on the disagreement slice. Real English corpus annotation is more informative than hint injection alone.

LLM model comparison (July 2026, 100-row Dutch eval)

Model Step B accuracy
qwen2.5:14b-instruct 76.3%
qwen2.5-coder (8B, baseline) 76.1%
mistral 7B 60.9%
llama3.1 8B 55.6%
cogito 8B 44.7%

Larger Qwen ≈ same as 8B coder on this slice; the gap is between Qwen and other 8B models. Both Qwen variants still score 0 on PRESERVING (too few gold rows).

Preservation side project (preservare)

Sibling work on VOC preservation techniques (salting, smoking, pickling, …) offers a scene-defined gold path: anchor on technique + recipe practice, not on disputed food lemmas. Planned as a separate eval slice (RECIPE_PRACTICE + PRESERVING + PR_Technique), then bridged into main TRIFECTA gold. Relevant for both languages if English recipe corpora are available.

Questions for joint discussion

  1. Regime taxonomy — Is the six-way text_regime list right for English corpora? What title/metadata do you have for auto-tagging?
  2. Coarse frames first? — Should both tracks adopt FOOD_TRANSFORM / OUT_OF_SCOPE before fine COOKING vs PRESERVING splits?
  3. English gold size and focus — Match Dutch (~50–125 core rows) with the same stratification (regime × frame × phenomenon)?
  4. WebAnno → pipeline import — Priority EN exports to import as silver/gold (which genres, which frames)?
  5. Shared edge bank — Can we align ambiguous phenomenon types (e.g. “water as ingredient vs reference”) across languages without shared snippets?
  6. Evaluation reporting — Agree to report Step B (and later Step C) per regime, plus a pooled number only as secondary?
